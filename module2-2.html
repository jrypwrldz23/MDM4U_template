Données en ordre :

Rappel

Moyenne

La somme de toutes les données divisée par le nombre de données : x̄ = Σx / n. Elle est influencée par les valeurs aberrantes.

Médiane

La valeur du milieu quand les données sont placées en ordre. Si n est pair, c’est la moyenne des deux valeurs du milieu. Elle résiste bien aux valeurs aberrantes.

Mode

La ou les valeurs qui reviennent le plus souvent. Il peut y avoir aucun mode, un mode ou plusieurs modes.

Laquelle choisir ?

Distribution symétrique : la moyenne. Distribution asymétrique ou avec valeurs aberrantes : la médiane. Données qualitatives ou valeur la plus fréquente : le mode.
